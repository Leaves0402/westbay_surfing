# 首頁預設圖片（fallback）

首頁圖片現在可以由幹部與管理員直接在網站上更換：登入後到首頁按「編輯首頁」，
就能上傳、裁切與排序 Hero、中段背景、幹部照片、QR Code 與頁尾背景。
上傳的圖片會存到 Supabase 的 `homepage-images` bucket，不會存在這個資料夾。

這個資料夾裡的圖片是**預設值**，只在以下情況顯示：

- `docs/sql/add_homepage_management.sql` 還沒執行
- 讀取 Supabase 失敗
- 資料庫裡還沒有對應的圖片

所以請保留這些檔案，首頁才不會在上述情況下變成空白。

## 檔案用途

- `hero/hero-01.webp` 到 `hero/hero-04.webp`：首頁最上方輪播圖
- `banner.webp`：首頁中段固定背景
- `officers/*.webp`：幹部照片
- `footer.webp`：頁尾背景

## 建議規格

- Hero：橫向 16:9，建議 2400 x 1350
- 中段背景、頁尾背景：橫向 2:1，建議 2400 x 1200
- 幹部照片：直向 4:5，建議 1000 x 1250
- 格式：WebP，單張建議控制在 500KB 左右
- 檔名：使用英文小寫，不要包含空格

透過網站上傳的圖片會自動裁切、縮放並轉成 WebP，不需要自己先轉檔。
若要直接替換這個資料夾的預設圖片，請沿用相同檔名，並可在
`lib/siteContent.ts` 調整 `objectPosition`（例如 `50% 35%` 會顯示較靠上的區域）。
